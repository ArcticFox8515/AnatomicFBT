# Consumed by audit-spike-symbols.ps1. Maintained BY HAND — update when the headers change.
#
# Format:  <declaring file>|<symbol>
#
# The symbol is the ONLY thing recorded. The search pattern is derived from it by the
# script, so a row can never be matched by text that is not a call to that symbol.
# (An earlier version of this file carried a hand-written search token per row; a
# destructor row then matched `class FakeX : public spike::X`, which is not a call to
# anything. Do not reintroduce a token column.)
#
# Scope: public only. Excluded are anonymous-namespace helpers in SpikeDriver.cpp /
# SpikeClient.cpp (internal linkage), SpikeObserver's four private methods
# (refreshDeviceMetadata, resolveComponents, logPoseSamples, logRates) and the
# protected VTableHookBase::originalFunction.
